# Game Boy Rail Shooter Editor

Простой редактор уровней и генератор ROM для рельсового шутера под оригинальный Game Boy.

## Что умеет

- Создавать простой проект рельсового шутера через графический интерфейс.
- Настраивать имя уровня, сложность, скорость, количество врагов, босс-файта и цветовую тему.
- Сохранять проект в JSON.
- Экспортировать в `.gb` ROM-файл для Game Boy Original.
- Включать демо-уровень для быстрого старта.

## Структура проекта

- `run_editor.py` — запуск редактора.
- `app/level_editor.py` — графический редактор.
- `app/rom_builder.py` — генератор `.gb` ROM.
- `projects/demo_rail_shooter.json` — пример проекта.

## Требования

- Python 3.10+
- ОС: Windows, macOS или Linux
- `tkinter` (обычно входит в стандартную поставку Python)

## Запуск

```bash
python run_editor.py
```

## Экспорт

После запуска:

1. Настройте параметры уровня.
2. Нажмите `Save Project`.
3. Нажмите `Export .gb`.
4. Готовый файл будет сохранён в папке `output/`.

## Ограничения

Это не полноценный игровой движок для Game Boy, а простой шаблон-редактор и генератор ROM с форматом игрового проекта для прототипирования рельсового шутера. Он подходит для быстрой разработки концепта и подготовки ROM-файла.
