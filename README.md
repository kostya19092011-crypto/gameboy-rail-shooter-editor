# Game Boy Rail Shooter Editor

Простой редактор уровней и генератор ROM для рельсового шутера под оригинальный Game Boy.

## Что умеет

- Создавать проект рельсового шутера через графический интерфейс.
- Настраивать параметры уровня: название, сложность, скорость, количество врагов, босс, тема.
- Редактировать дорожку уровня в визуальном режиме: сегменты, враги, бонусы, боссовые участки.
- Сохранять проект в JSON.
- Экспортировать готовый `.gb` ROM-файл для Game Boy Original.
- Поддерживать демо-уровень для быстрого старта.

## Структура проекта

- `run_editor.py` — запуск редактора.
- `app/level_editor.py` — визуальный редактор уровня и GUI.
- `app/rom_builder.py` — генератор `.gb` ROM.
- `projects/demo_rail_shooter.json` — пример проекта.

## Требования

- Python 3.10+
- ОС: Windows, macOS или Linux
- `tkinter` (обычно входит в стандартную поставку Python)

## Запуск

```bash
python run_editor.py
```

## Экспорт

После запуска:

1. Настройте параметры уровня.
2. Используйте панель редактора уровня слева/справа.
3. Нажмите `Save Project`.
4. Нажмите `Export .gb`.
5. Готовый файл будет сохранён в папке `output/`.

## Ограничения

Это не полноценный игровой движок для Game Boy, а удобный прототип редактора уровней и генератор ROM-метаданных для быстрого концептирования рельсового шутера и подготовки `.gb`-файла.
