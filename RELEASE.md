# Game Boy Rail Shooter Editor - Release Build\n\n## Быстрый старт\n\n### На Windows:\n\n1. **Запустите сборку:**\n   ```bash\n   build_windows.bat\n   ```\n\n2. **Дождитесь завершения** (первый раз займет 2-3 минуты для загрузки зависимостей)\n\n3. **Готовый файл:**\n   ```\n   dist/GameBoy Rail Shooter Editor.exe\n   ```\n\n4. **Запустите редактор:**\n   - Двойной клик на `GameBoy Rail Shooter Editor.exe`\n\n## Что получится\n\n- Полнофункциональный редактор уровней для рельсового шутера Game Boy\n- Экспорт в `.gb` ROM-файл\n- Работает без установки Python\n- Портативный файл (можно перемещать и делиться)\n\n## Требования для сборки\n\n- Windows 7 и выше\n- Python 3.10+ (установлен на компьютер)\n- ~500 МБ свободного места на диске\n\n## Ошибки при сборке\n\n### \"Python not found\"\n- Установите Python с https://www.python.org/\n- Убедитесь, что Python добавлен в PATH\n\n### \"PyInstaller not found\"\n- Запустите: `pip install pyinstaller`\n\n### \"Permission denied\"\n- Запустите CMD с правами администратора\n\n## После сборки\n\nГотовый `GameBoy Rail Shooter Editor.exe` можно:\n- Запустить с любого места\n- Скопировать на другой компьютер\n- Отправить друзьям\n- Поместить на флешку\n\n## Файлы проекта\n\nВ папке `projects/` находятся примеры проектов в формате JSON.\n\nПосле экспорта файлы `.gb` появляются в папке `output/`.\n\n## Лицензия\n\nMIT\n
